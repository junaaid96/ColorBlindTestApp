Features

Screening, simulation and everyday help in one app

Most apps only test or only assist. Color Vision Lab does both, fully offline.

Tests

🔵

Quick & full screening

7-plate quick check or full 16-plate test with control, red-green, tritan and protan/deutan plates. Generated on the fly from Machado confusion lines, so they can’t be memorised.

🌈

Hue arrangement (D-15)

Order 15 caps by hue. Scored with Vingrys & King-Smith: confusion index, selectivity, crossings and likely axis. Tap, drag or use the keyboard.

◐

Contrast sensitivity

A four-direction arrow with an adaptive 1-up/2-down staircase that reports log CS.

📄

Results & report export

Type, severity, confidence and a per-plate breakdown. Share it, or export a printable HTML report and save it as PDF.

Tools

📷

Live Color Lens

Point your camera (or a photo) at anything: it names the colour under the crosshair, simulates or enhances in real time, freezes frames and can speak names aloud.

🖼️

Photo simulator + correction

See a photo as protan, deutan and tritan side by side, adjust severity, toggle daltonize correction and save any panel as PNG.

📈

History & streaks

Trend charts per test, CSV export, JSON backup and restore. Everything stays on your device.

🔥

Daily practice

A 60-second odd-hue game with levels, lives, a best score and a daily streak. No notifications, no dark patterns.

Built for everyone

📴

Offline & privacy-first

No accounts, analytics or ads. Results are stored locally. The only network call is the optional, signature-verified desktop update check.

🌓

Themes & calibration

System, light and dark themes, a high-contrast mode and a grey-step calibration check before plate tests.

🌐

Multilingual

English, বাংলা, Español and हिन्दी, with an English fallback.

⌨️

Keyboard & screen reader

Okabe-Ito palette, never colour alone, live regions and labels, reduced motion and full keyboard control (1–7 sections, ? shortcuts).

Under the hood

Why Tauri?

Version 3 moved from a native Kotlin Android app to Tauri v2: a Rust core with a React + TypeScript UI rendered by the system webview. Here is the honest trade-off.

🪶

Tiny installers

The Windows installer is about 2.4 MB and the macOS universal app about 6 MB, because Tauri uses the OS webview instead of shipping Chromium. Comparable Electron apps typically start around 100 MB+.

🧩

One codebase, every platform

The same TypeScript colour science, tests and UI ship on Windows, macOS, Linux, Android and iOS, and the exact same code is reused as the web build.

🦀

Rust where it matters

Photo simulation and daltonize run in a small Rust pixel pipeline; the web build falls back to TypeScript with identical maths.

🛡️

Security by default

Capabilities and permissions allow only the APIs each window needs, a strict Content Security Policy blocks remote code, and there is no Node runtime in the app.

🔌

Native plugins

Official plugins for the file system, dialogs, notifications, deep links, single instance and window state give native behaviour without custom glue.

🔄

Signed auto-updates

Desktop apps check GitHub Releases and only install updates whose signature matches the public key built into the app.

Trade-offs: the UI depends on each OS’s webview (WebView2, WKWebView, WebKitGTK, Android System WebView), so rendering is tested per platform; Linux AppImages are larger because they bundle libraries; and mobile support in Tauri is newer than on desktop.

Private by design

No accounts, analytics or ads. Results never leave your device. The camera is used only for the Color Lens and frames are processed locally. Read the privacy policy.

Screening, not a diagnosis

Color Vision Lab is an educational screening tool, not a medical device. Screens vary in colour and brightness. If you are concerned about your vision, see an eye-care professional.

FAQ

Questions

Is this a medical diagnosis?

No. It screens and educates. Results depend on your display, lighting and settings, so treat them as an indication and see an eye-care professional for a diagnosis.

How accurate are the plates?

Plate colours are found on Machado 2009 confusion lines with lightness noise, so brightness gives no clue, and a calibration check runs first. Uncalibrated screens still limit accuracy.

Is my data private?

Yes. Everything is stored on your device. There are no accounts, analytics, ads or servers. The desktop update check only downloads a public file from GitHub.

Which platforms are supported?

Windows 10+, macOS 11+, modern x86_64 Linux, Android 7.0+ and any modern browser. iOS builds can be made from source with Xcode; until then, use the web app.

Is the Android APK safe to install?

Yes. It is a signed release build (23 MB) made by the public GitHub Actions workflow. Its signing certificate SHA-256 is 4A:CF:80:E0:87:E8:3C:BD:C5:06:E0:1C:AA:BB:FA:96:CF:B7:11:C5:AF:3B:34:A1:BD:01:8D:B6:6B:F7:55:12, and future updates use the same key.

Does it work offline?

Yes. Native apps bundle everything, and the web app caches itself with a service worker after the first visit.

Is it open source?

Yes, under the MIT license. The code, issues and releases are on GitHub. Contributions are welcome.

How do I update?

Desktop apps update themselves from Settings. On Android, install the newer APK over the old one. The web app updates on reload.
