Everything in one app

Ishihara-style plates

A quick 7-plate screening or a full 16-plate test. Plates are made on the device from confusion-line colours, so you can't memorise them.

Result report

Shows type, severity and confidence, with a breakdown for each plate. Share it as text or PDF.

Hue arrangement (D-15 style)

Put 15 caps in order. It is scored with confusion index, selectivity, crossings and the likely axis.

Contrast sensitivity

An adaptive staircase on a faint directional arrow gives you a log CS score.

Color Lens

The live camera names the colour under the crosshair. It can simulate protan, deutan and tritan vision, or enhance colours in real time, and it can speak names aloud.

Photo simulator

Compare any photo side by side as seen with each type of colour vision deficiency. It has a severity slider and a daltonize toggle.

Daily practice

A 60-second odd-hue game with levels, lives, a best score and a daily streak.

4 languages and accessible

English, বাংলা, Español and हिन्दी. It uses a colour-blind-safe palette, TalkBack labels, a high-contrast theme and reduced motion. History trends are kept on your phone.

How it works

  1. Download and install the app for your computer or phone, or open the web version in a browser.
  2. Take a test. Start with the quick 7-plate screening, then try the full, hue and contrast tests.
  3. Read your report. It shows type, severity and confidence, and you can track trends in History.
  4. Explore. Point the Color Lens at the world or run photos through the simulator.

Installing

  1. Windows: run the .msi or -setup.exe.
  2. macOS: open the .dmg and drag the app to Applications. Unsigned builds need right-click → Open the first time.
  3. Linux: use the .AppImage, .deb or .rpm.
  4. Android: install the .apk and allow install unknown apps if asked.

About warnings

Builds are not yet code-signed with a store certificate, so Windows SmartScreen, macOS Gatekeeper or Google Play Protect may warn you. The full source is public, and you can build it yourself with npm run tauri build.

Private by design

The app makes no network calls except the optional desktop update check against GitHub Releases. It has no accounts, analytics or ads. Your results never leave your device. The camera is used only for the Color Lens and processes frames on the device.

Screening, not a diagnosis

Color Vision Lab is a screening and learning tool. It is not a medical device. Screens vary in colour and brightness. If you have any concerns about your vision, see an eye-care professional.

FAQ

Is it free?

Yes. It is free and open source under the MIT license.

Which devices are supported?

Windows 10+, macOS 11+, modern Linux desktops, Android 7.0+ and any modern browser. iOS builds can be made from source with Xcode.

Is it in an app store?

Not yet. Downloads come from the GitHub releases page, and there is a web version that works offline.

How accurate is it?

The plates use the Machado 2009 confusion-line model, with lightness noise so brightness gives no clue. Results still depend on your screen, so treat them as an indication.

Why does my device warn me?

Operating systems warn about apps installed from outside their stores or without a paid signing certificate. See the install section above.

How do I update?

Desktop apps check GitHub Releases from Settings and update themselves. On Android, install the newer APK over the old one.
